# Before sharing an experiment

- [ ] One clear question and a scoped conclusion.
- [ ] Code, pinned dependencies, configuration and run/evaluation commands.
- [ ] Source paper and upstream code attribution.
- [ ] Dataset split, seeds, episode count, hardware and compute budget.
- [ ] Results table with metric definitions and uncertainty where applicable.
- [ ] A figure or video plus at least one representative failure.
- [ ] Differences between toy implementation, reproduction and proposed extension are explicit.
- [ ] Personal correspondence, large datasets and checkpoints are excluded.
- [ ] Short write-up explains what was learned and the next experiment.
