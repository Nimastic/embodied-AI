# Reusable working templates

Copy [paper-note.md](paper-note.md) for a deeper reading note and [experiment-report.md](experiment-report.md) for each meaningful comparison. Stage `results.csv` files contain headers only; each row should be a real measurement. Keep full configuration files alongside code and link them by path in the CSV.

Before sharing a stage, use [publish-checklist.md](publish-checklist.md). Sharing is a later manual step; this roadmap does not post to any service.
