# Where this roadmap came from

The original pasted conversation is preserved locally as `conversation-original.txt` and excluded from Git because it includes personal correspondence. The numbered learning stages and implementation choices are our synthesis of that conversation, not additional instructions from the professors.

Harold Soh's quoted reply names planning as inference, MPPI, MPC, diffusion and autoregressive generative models, and encourages understanding the older ideas beneath modern methods. Yuejiang Liu's quoted reply recommends learning common codebases and simulators, reproducing a recent paper, and using that experience to discover a research question.

The named papers, benchmark choices and suggested public projects were recommendations in the surrounding conversation. Neither quoted reply supplies that full bibliography. The paper library includes all 13 distinct papers named in the conversation plus Tedrake's course notes. Generic labels such as WAMs and VLA / Robot Foundation Models are topics, not additional uniquely specified publications.
